# R-DSA — DSA Practice

Monk mode repo. No autocomplete, no suggestions — syntax highlighting only.

The `.vscode/settings.json` disables all editor assistance so every line is written from memory. Clone and the settings apply automatically in VSCode.

## Structure

Organize solutions however you like. Suggested layout:

```text
arrays/
trees/
graphs/
dp/
strings/
```

## Rules

- No peeking at autocomplete
- No Copilot / AI suggestions
- Struggle is the point
